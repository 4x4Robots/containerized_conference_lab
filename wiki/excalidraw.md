# Excalidraw

## Self-hosted

Self-hosting excalidraw with collaborating features is hard. Thankfully PatWie has already done the work: [https://github.com/PatWie/excalidraw-complete](https://github.com/PatWie/excalidraw-complete)

Run it on Port 3002 with
```sh
~/Downloads/excalidraw-complete
```
